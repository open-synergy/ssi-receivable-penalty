===========================================
Account Receivable Penalty + Operating Unit
===========================================

Glue module that adds Operating Unit support to the Account Receivable Penalty
module. Extends ``account.receivable_penalty``, ``account.receivable_penalty_computation``,
and ``batch_receivable_penalty_computation`` with ``mixin.single_operating_unit``,
so account receivable penalty documents can be scoped and restricted per
operating unit.
